# iPhone 实现状态

日期：2026-10-19。原生源码位于 `app/Kiseki/`；开发文档和原型位于 `app/docs/`。所有真机验收由用户后续在 iPhone 13 mini／iOS 27.2 执行。

## 已实现

- SwiftUI 作品首页和照片／声音／画面／预览编辑区，系统图库有序选片、文件导入、内容滚动中的制作按钮。
- App 内素材副本、图片摘要去重、显式顺序、原子清单、revision 保护、重开草稿、删除作品与成果、清理未引用文件。
- 同一原生 frame renderer 提供低分辨率预览、全尺寸 PNG 和 1080p／60 fps H.264；本地音频经 AVFoundation 合成到 MP4。
- 统一使用日记排版，支持胶片效果与画面过渡，不提供呈现方式选择。签名、片尾、日期章节和符合条件的开场快放可在更多画面细节中选用。原生排版尚未证明与桌面逐像素或视觉等价。
- LRC 原文／双语解析、歌词显示与整体偏移、试听校对；LRCLIB 候选查询和确认。支持手工旁白及通过 DeepSeek 生成／补齐旁白。
- API Key 在仅本机、解锁可访问的 Keychain 中存储；图片上传需用户确认，缩略图重新编码以不携带原图元数据。
- 多版本成果、系统播放器、PNG 查看、系统分享、按需请求添加到照片权限。
- 带 SHA-256 摘要的目录式草稿备份和受限恢复，排除 Key、成果和模型；校验路径、文件类型、总量和格式版本。
- 按操作检查照片／音频文件、计划时长、编码配置、空间、温度和任务占用；设置显示本机状态与在线服务最近结果。磁盘写入、编码和网络在实际执行中仍可能失败，会保留草稿并报告错误。
- 任务日志和启动恢复：中断任务不会被当成成果，不承诺从中间帧续跑。

## 验证记录

使用 Xcode 27.1／iOS 27.1 SDK，专用 iPhone 13 mini 模拟器，runtime iOS 26.5。未修改系统全局 `xcode-select`。

- 已完成一次 30 张合成示例照片、90 秒无声导出。Mac 上 ffprobe 检测为 H.264、1920×1080、30/1 fps、90.000 秒、2700 帧。测试素材是生成的示例，不覆盖真实 HEIC／HDR、iCloud 或真机温控。
- 最终 Debug 模拟器 App 约 15 MB，未签名的真机架构 Release App 约 8.6 MB，含两款签名字体，不含任何识别模型。这是构建目录大小，不是签名后的下载或安装占用；素材、备份和成果另计。
- 最终独立回归通过 19 项单元测试与 1 项 UI 测试，真机架构未签名 Release 构建成功。原生自动测试覆盖 PNG、带音轨视频、输出时长／尺寸与关键像素、字体注册、显式排序、开场快放预留、旧清单写入保护、中断恢复、备份篡改检测、路径拒绝和 LRC。UI 测试覆盖从编辑页导出并进入成果。
- 已通过模拟器系统图库实际导入图片，再选同一图片仍为一张；重启后草稿存在。可选 Keychain 读取失败只显示在旁白服务状态，不阻塞本地操作。
- 完整命令与证据见 [本次验证记录](validation-report.md)。
- LRCLIB 的一次真实查询返回 503 ServerOverloaded，未验证成功搜索。App 保留本地 LRC 和无歌词路径；不把该错误解释成 VPN 问题。
- DeepSeek 的请求格式按官方图像接口实现，使用 `deepseek-flash`。未使用真实 Key 调用，线上成功、费用与不同语言照片质量待用户验收。

## 当前范围

未接入在线音乐获取、离线识别模型、AMLL、后台持续出片、4K，以及桌面全部滤镜。本地音频可自动分析节拍并跟随节拍安排照片，算不出拍子时改回均匀节奏；歌词需要用户试听校对。App 不下载 Node、Python、FFmpeg 或浏览器。

测试代码和基于模拟器的结果不能证明真机速度、照片权限、分享目的地、iCloud 下载、真实照片色彩或发布签名已通过。安装与手工检查见 [iPhone 验收步骤](iphone-testing.md)。

## 外部接口依据

- [DeepSeek 图像接口](https://api-docs.deepseek.com/guides/vision/)：当前 Flash 接收用户消息中的图像，旧实验模型名称已由新模型承接。
- [LRCLIB API](https://lrclib.net/docs)：仅在用户搜索时查询，不自动将歌词结果应用到作品。

## 画面默认与操作位置

新建作品默认竖版、浅色、显示已有旁白、每张 4 秒；EXIF、片头、开场快放、日期章节、签名均关闭，签名和片尾为空。使用整首音乐时由音乐时长均分画面。已有草稿保留用户的开关选择；预览和导出统一应用画面效果与日记排版。

照片页的添加、补齐旁白、排序在网格之前；声音页的清除歌词在歌词长列表之前；预览页输出方式、静态图选片与制作入口在预览图之前。编辑页使用稳定的滚动容器，切换时不主动重置工作位置。操作随内容滚动，底部只保留编辑导航。画面页常用设置直接显示，附加效果收在“更多画面细节”。

## 声音、静态图与设置交互

声音页以选项卡显示当前无声／本地音乐状态，点击无声会确认选择；音乐和 LRC 共用一个系统文件选择器入口，按操作切换文件类型。导入音乐后显示文件名，取消文件选择保留原状态。

静态图使用可横向滚动的照片缩略图、选中边框、当前位置和上一张／下一张按钮，切换时自动将缩略图滚到可见范围。设置页按旁白与歌词、本机状态、存储与备份分组，在线状态纵向换行显示；能力说明收在展开项中。
