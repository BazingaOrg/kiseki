# 在 iPhone 上安装与验收

用户的目标设备为 iPhone 13 mini、iOS 27.2。真机测试由用户执行；当前记录只包含模拟器证据。

## 安装

1. 用 Xcode 打开 `app/Kiseki.xcodeproj`，选择应用 target `Kiseki`。
2. Signing & Capabilities 中选自己的 Personal Team，启用自动签名；为 Bundle Identifier 使用唯一且长期保持不变的标识。
3. 连接 iPhone、解锁并信任电脑；根据系统提示启用 Developer Mode。在 Xcode 选择这台手机作为运行目标。
4. Run。若 Xcode 报设备系统版本不受支持，先按其具体提示补齐兼容版本／设备支持。本项目当前以 Xcode 27.1 和 iOS 27.1 SDK 编译，尚未验证对该手机的调试连接。
5. 免费签名到期后用同一 Team 和 Bundle ID 重新构建安装，不要求先卸载。卸载 App 会清除容器，务必先导出草稿备份。

## 首次真实素材闭环

- 从图库新建日记，选择 8–20 张照片；观察 iCloud 原图准备是否完成，再强制退出并重开，检查草稿和顺序。
- 长按拖动顺序；轻点照片手写旁白并保存。移除一张照片，检查系统图库原件仍在。
- 在声音页导入“文件”中的音乐；导入 LRC，试听并手调歌词偏移。也可不加音乐完成无声作品。
- 在画面页选择横／竖／方形，确认默认原图色彩、4 秒停留和旁白显示；展开“更多画面细节”检查签名、片尾、展签和日期章节；在预览页拖动时间检查。
- 视频与 PNG 各导出一次，保持 App 在前台。检查时长、方向、颜色、顺序、字幕、声音和照片边界；随后保存到照片并分享。
- 拒绝保存到照片权限后，确认成果仍能留在 App 并通过分享保存到文件。

## 资源与异常

- 30 张照片制作 90 秒 1080p／30 fps，记录耗时、可用空间变化、温度感受和电量变化。模拟器耗时不能替代这组结果。
- 中途取消、切到后台或强制退出；重开确认草稿可用，没有半成品被当成成果。后台会请求取消渲染，当前不承诺后台持续出片或从中间帧恢复。
- 系统空间不足、音频过短、素材无法读取时，检查是否给出具体提示，修复后能重新制作。
- 用深浅色、较大字体、VoiceOver 检查预览页，确保制作按钮能滚动到达且不被底部编辑导航遮住。
- 导出草稿备份，在首页左上角恢复，检查照片、顺序、旁白、音乐、歌词和设置。备份目录为 `.kisekiproject`，不含成果、Key 或模型。

## 可选在线旁白

在设置里输入自己的 DeepSeek Key。保存到 Keychain 并不代表验证成功；只有你确认生成时才发送 640 像素以内、重新编码的 JPEG 预览。一次成功生成后，再检查批量补齐、已有文字保留、重写确认、网络失败与取消。

真实 Key、费用、服务响应和手机网络尚未验收。不要把密钥放到仓库或测试报告中。在线搜歌、离线识别模型、AMLL 及自动踩点当前未接入。
