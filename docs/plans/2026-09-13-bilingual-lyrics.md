## 验收

单一来源失败不阻断另一来源；原文与译文保持对应、一起保存与偏移；无译文明确回退原文；不重复识别或翻译；旧项目兼容；三种视频布局和缺译文、长句不重叠越界。下载结果用于离线渲染。

## 数据与显示契约

AMLL 的搜索使用 `/v1/lyrics/search`，详情使用 `/v1/lyrics/get?id=...`。候选身份为来源与 ID 的组合；AMLL 搜索结果没有音频时长，不据此声明时长吻合。详情中的 TTML 经过有界 XML 解析，按段取原文及已有中文译文，过滤音译与背景人声。

本地仍保存单个 `.lrc`。原文使用标准时间行，中文译文使用同时间戳及显式 `[kiseki:translation:zh-CN]` 角色标记；文件头保留来源、ID 和贡献者。解析器只识别声明式译文，不猜测普通重复时间戳的语言角色。结束时间转换为空时间行，保留间奏清屏。

分析器、timeline 与网页统一使用可选 `translation: {text, lang: "zh"}`。时间轴校验只比较原文，校准时两种文本一起移动。显示切换通过 Web `lyricsMode` / CLI `--lyrics-mode` 传到运行时 `meta.lyrics_mode`，不写回 timeline 或触发歌词再识别。默认双语，有译文的轨道保留固定两行位置；整轨无译文时保持单语布局。
